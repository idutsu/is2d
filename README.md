# is2d

Adobe Animate（旧 Flash）の描き心地で、手描きのライトなアニメを作るための 2D アニメ制作ソフトです。
Animate の機能のうち、手描きのアニメに本当に要るものだけに絞り、そのぶん軽く・速く・壊れにくく作っています。

## できること

- **描く**：ブラシ・消しゴム・バケツ・スポイト。同じ色で接した図形は1つにまとまり、色の違う図形の境目は線1本を共有する、Animate と同じ描き方（結合描画）。輪郭のフチや角をつまんで、粘土のように形を変えられる
- **整える**：選択・自由変形・グループ・重ね順・コピーと貼り付け
- **動かす**：タイムライン（レイヤー・キーフレーム・コマ）、オニオンスキン、グラフィックシンボル（入れ子のタイムライン・再生の設定・色効果）、クラシックトゥイーン
- **音**：WAV・MP3 をキーフレームに付け、タイムラインの波形の端をドラッグして始まりと終わりを決める。再生やスクラブで、絵に合わせて鳴る
- **書き出す**：音入りの動画（MP4・H.264・AAC）
- **守る**：Undo / Redo、壊れたファイルを見分ける保存、確認なしで終わったときの復旧

テキスト・シェイプトゥイーン・マスク・ボーンなど、手描きのライトアニメに要らない機能は、あえて入れていません。

## 動く環境

| | 描く・アニメ・音 | 動画の書き出し |
|---|---|---|
| macOS | ○ | ○ |
| Windows | ○ | ○（Windows の動画の機能を使う。N エディションでは「メディア機能パック」が要る） |
| Linux | ○ | ×（ビルドして動かすことはできる） |

## ビルドと起動

[Rust](https://rustup.rs) を入れてから、このフォルダで次を実行します。

```
cargo run --release
```

- Windows では、Rust を入れるときに案内される Visual Studio の C++ ビルドツール（MSVC）が要ります。
