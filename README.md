# animelite — Flash Brush & 2D Vector Animation Studio

Macromedia Flash（現 Adobe Animate）の **「ブラシツール（マージ描画モード）」** の描き心地・粘土のような輪郭変形体験・X-Sheet タイムライン・シンボル＆クラシックトゥイーンを Rust で実装した 2D ベクタードローイング＆アニメーション制作アプリケーションです。

中心線（ストローク）の概念を持たず、すべての描線を **「閉じた2次ベジェ曲線の塗り輪郭（Filled Shape）」** として生成・ブーリアン結合・直接変形します。

---

## 技術スタック

- **言語**: Rust (Edition 2021)
- **GUI・ウィンドウ・入力制御**: [`eframe`](https://crates.io/crates/eframe) (`egui` 0.30)
- **曲線計算・幾何データ構造**: [`kurbo`](https://crates.io/crates/kurbo)（2次ベジェ曲線 `QuadBez`・アフィン変換・De Casteljau 分割）
- **2D ブーリアン演算・自己交差解消**: [`i_overlay`](https://crates.io/crates/i_overlay)（`FloatOverlay` による高速・堅牢な `Union` / `Difference` / `Intersection` / `SimplifyShape`）
- **ポリゴン分割（テッセレーション）**: [`lyon_tessellation`](https://crates.io/crates/lyon_tessellation)（閉じた2次ベジェ輪郭と穴の高速 GPU メッシュ化）

## 主な機能

### 1. ベクターブラシ＆マージ描画（Merge Drawing）
- **閉輪郭生成＆100%スムージング**: マウスドラッグ中の軌跡から一定幅＋丸端キャップの閉輪郭を生成し、離した瞬間に `i_overlay::SimplifyShape` による自己交差解消、コーナー・丸端保護付きのゼロ収縮平滑化、最小二乗フィット＋G1接線連続化によって滑らかな **2次ベジェ曲線（`QuadBez`）** の閉ループへ変換します。
- **同色自動結合・異色自動切り抜き**: 同じレイヤー・同じグループ階層内で重なった生シェイプに対し、同色なら `Union` で1つに融合し、異色なら `Difference` で下の絵を切り抜き、De Casteljau 法でベジェ曲線を無劣化に再構築します。
- **バケツ塗り（`K`）・消しゴム（`E`）・スポイト（`I`）**: 複数レイヤーの線で囲まれた閉領域（穴）へのベクター色流し込み、選択領域のみへの色流し込み、既存シェイプのリカラー、消しゴムによるベクター減算、最前面カラーの抽出に対応しています。

### 2. 選択ツール（`V`）・輪郭の粘土変形（Reshape）・自由変形（`Q`）
- **マーキー部分スライス選択**: 生シェイプの一部を矩形ドラッグで囲むと、囲んだ範囲だけがナイフで切り出されたように選択状態（白い網点表示）になり、未編集で選択解除すれば元の1つの図形に無劣化で戻ります（`Shift` で複数箇所の連続スライス選択に対応）。
- **ハンドルなしの輪郭つまみ変形**: 未選択シェイプの輪郭エッジを直接ドラッグして曲線を曲げたり、反対側の輪郭まで突っ切って2つの図形に分割したりできます。頂点（角）のドラッグ移動と近傍頂点へのスナップ吸着、および `+` / `-` キーによるアンカーポイントの追加（De Casteljau 分割）・削除（直線化）にも対応しています。
- **自由変形ツール（`Q`）**: バウンディングボックスの8方向スケールハンドル（対辺越えドラッグによる反転、`Shift` で縦横比固定、`Alt` でピボット中心対称）、四隅外側の回転（`Shift` で15°スナップ）、カスタムピボット（`○`）の自由移動（ダブルクリックで中心リセット）を行えます。

### 3. ネストグループ（`Cmd+G`）＆グラフィックシンボル（`F8`）
- **グループ化とインプレイス編集**: 選択図形を `Cmd/Ctrl + G` でグループ化（多段ネスト対応）すると、他の生シェイプと重なっても切り抜かれずに独立したパーツとして共存します。ダブルクリックでグループ内部へ潜り（上部パンくずリストで階層表示）、周囲を減光表示したまま内部パーツだけを直接編集できます。
- **シンボル＆ライブラリ＆独自タイムライン**: `F8` キーで選択図形をグラフィックシンボルに変換して右パネルの `ライブラリ` タブへ登録できます。ライブラリから複数インスタンスを配置でき、シンボルをダブルクリックすると**シンボル専用の独立タイムライン**に切り替わって内部アニメーションを作成できます。
- **シンボル再生オプション（ループ / 1回再生 / 任意のフレーム）**: ステージ上の各シンボルインスタンスごとに、右パネルの「シンボル再生設定」から `ループ`・`1回再生`・`任意のフレーム`（口パク・目パチ等のコマ切り替え）と開始/指定フレーム番号を個別に設定できます。

### 4. マルチレイヤー X-Sheet タイムライン＆クラシックトゥイーン（`T`）
- **マルチレイヤー＆キーフレーム操作**: レイヤーの追加・削除・ドラッグ＆ドロップ重ね順変更・表示/非表示（👁）・ロック（🔒）、`F6`（複製キーフレーム）・`F7`（空白キーフレーム）・`Shift+F6`（キーフレーム削除）・`F5`（フレーム延長）・`Shift+F5`（フレーム短縮/削除）、選択フレーム範囲のドラッグ移動＆`Alt`+ドラッグ複製に対応しています。
- **クラシックトゥイーン（`T` キー）**: 単一のシンボルインスタンスのみが配置されたキーフレームで `T` キー（または `T Tween` ボタン）を押すとクラシックトゥイーンが有効になります。直後のキーフレームに同じシンボルの単一インスタンスがあればタイムライン上に**実線矢印**が表示され、位置・回転・スケール・反転（TRS分解）を自動補間します（条件未達時は**横点線**を表示）。
- **オニオンスキン（`O` キー）＆3段階メッシュキャッシュ**: 前後フレームを距離に応じた透過色（過去＝青、未来＝緑）で重ねて表示します。セル単位の3段階キャッシュ（ローカルメッシュ → ワールドバッチメッシュ → スクリーン/オニオンメッシュ）により、再生中は図形クローンや再テッセレーションを一切行わない O(1) ゼロコピー再生を実現しています。

### 5. ステージ枠（カメラフレーム）＆クリッピングマスク
- キャンバス中央にカメラ出力領域を示す白い**ステージ枠**（初期値 `1280 × 720`）と周囲のグレーの作業机（ペーストボード）を表示します。
- 上部ステージバーからステージの幅・高さ・背景色を自由に変更でき、**`枠外を隠す`** ボタンを ON にするとステージ外にはみ出した作画を半透明ベールでマスクしてカメラフレーム内の完成画面を確認できます。

## ショートカットキー一覧

| キー | 機能 |
| :--- | :--- |
| **`V`** | **選択・輪郭変形ツール**（塗りの選択・移動、マーキー部分スライス、エッジつまみ変形、頂点移動＆スナップ） |
| **`Q`** | **自由変形ツール**（8方向拡大縮小、回転、反転、基準点ピボット移動） |
| **`B`** | **ブラシツール**（マージ描画・100%スムージング2次ベジェ曲線生成） |
| **`E`** | **消しゴムツール**（描いた軌跡で既存シェイプをブーリアン減算・切断） |
| **`K`** | **バケツツール**（閉領域へのベクター色流し込み、既存シェイプまたは選択領域の色変更） |
| **`I`** | **スポイトツール**（クリック位置の最前面シェイプから塗りカラーを抽出） |
| **`+` / `-`** | 選択ツール（`V`）の**アンカー追加モード** / **アンカー削除モード**切り替え |
| **`F8`** | 選択中の図形を**シンボルに変換**してライブラリへ登録 |
| **`T`** | 現在キーフレームの**クラシックトゥイーン** ON / OFF 切り替え（単一シンボル配置時） |
| **`F6` / `Shift + F6`** | **複製キーフレーム挿入**（先頭なら次コマへ進行） / **キーフレーム削除** |
| **`F7`** | **空白キーフレーム挿入**（描画済みKF先頭なら次コマへ進行） |
| **`F5` / `Shift + F5`** | **フレーム延長（+1コマ）** / **フレーム削除・短縮（-1コマ）** |
| **`Enter`** | タイムラインの**再生 / 一時停止** |
| **`,` / `.`** | **前のフレーム（`<`）** / **次のフレーム（`>`）** へ1コマ移動 |
| **`O`** | **オニオンスキン** ON / OFF 切り替え |
| **`Cmd/Ctrl + G` / `B`** | **グループ化** / **グループ解除（1階層展開）** |
| **`ダブルクリック`** | グループまたはシンボルの**内部へ潜る（インプレイス編集）** / 空き領域ダブルクリックで1階層上へ戻る |
| **`Cmd/Ctrl + C` / `X`** | 選択図形の**コピー** / **カット** |
| **`Cmd/Ctrl + V` / `Shift + V`** | **ペースト**（オフセット配置） / **同じ位置にペースト** |
| **`Cmd/Ctrl + Z` / `Y`** | **元に戻す（Undo）** / **やり直し（Redo）** |
| **`Space + ドラッグ` / `ホイール`** | キャンバスの**パン（移動）** / **カーソル中心ズーム**（`Cmd/Ctrl + 0` で 100% リセット） |
| **`Esc`** | **選択解除**（未選択時はグループ/シンボル編集階層から1段階出る） |
| **`Delete` / `Backspace`** | 選択中の図形・スライス領域を**一括削除** |
| **`↑` `↓` `←` `→`（選択中）** | 選択中の図形を **1px ずつ移動**（`Shift + 十字キー` で **10px ずつ移動**） |
