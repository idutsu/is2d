# animelite — Flash Brush & Merge Vector Engine

Macromedia Flash（現 Adobe Animate）の **「ブラシツール（マージ描画モード）」** の描き心地と輪郭変形体験に特化した、Rust 製の2Dベクタードローイングアプリケーションです。

中心線（ストローク）の概念を持たず、すべての描線を **「閉じた2次ベジェ曲線の塗り輪郭（Filled Shape）」** として生成・ブーリアン結合・直接変形します。

---

## 技術スタック

- **言語**: Rust (Edition 2021)
- **GUI・ウィンドウ・入力制御**: [`eframe`](https://crates.io/crates/eframe) (`egui`)
- **曲線計算・幾何データ構造**: [`kurbo`](https://crates.io/crates/kurbo)（2次ベジェ曲線 `QuadBez`・パス計算・De Casteljau 分割）
- **2D ブーリアン演算・自己交差解消**: [`i_overlay`](https://crates.io/crates/i_overlay)（`FloatOverlay` による高速・堅牢な `Union` / `Difference` / `SimplifyShape`）
- **ポリゴン分割（テッセレーション）**: [`lyon_tessellation`](https://crates.io/crates/lyon_tessellation)（閉じた2次ベジェ輪郭と穴の高速 GPU メッシュ化）

---

## 実装されている4つの核心アルゴリズム

1. **ブラシ軌跡からの「閉じた輪郭（アウトライン）」生成**
   - マウスドラッグ中の座標列 `(x, y)` とブラシ半径 `r`（および移動速度に応じた太さ変化 `Vel Taper`）から、進行方向に対する左右の法線オフセット点列と始点・終点の半円キャップを計算し、単一の閉じた輪郭パス（Closed Contour）を生成します。
2. **マウスを離した瞬間の「Flash風スムージング」と2次ベジェ曲線化**
   - ドラッグ中は生のポリゴンとしてリアルタイムプレビュー描画し、マウスを離した瞬間に以下を実行します：
     1. `i_overlay` の `SimplifyShape`（`FillRule::NonZero`）で急カーブや8の字ストロークの自己交差を解消し、外周と穴の階層を抽出。
     2. **Ramer-Douglas-Peucker (RDP) 法** で輪郭のノイズ頂点を間引き（UI の `Smoothing: 0〜100` スライダーで間引き強度を調整可能）。
     3. 間引いた頂点列を、最小二乗フィッティング＋接線連続性補正によって滑らかな **2次ベジェ曲線（`kurbo::QuadBez`: 始点・制御点1つ・終点）** の閉ループへ変換。
3. **マージ描画（`i_overlay` による同色の自動結合・異色の自動切り抜き＆2次ベジェ再フィッティング）**
   - 各シェイプは `色（Color32）` と `閉じた2次ベジェ輪郭のリスト（外周 exterior および穴 holes）` を保持します。
   - ストローク確定時に `i_overlay::float::overlay::FloatOverlay` を用いてブーリアン演算を実行し、出力されたポリゴンリングから元の `QuadBez` セグメントへの照合＋**De Casteljau 法（`QuadBez::subsegment`）** および **コーナー保持 RDP＋最小二乗2次ベジェ再フィッティング** によって滑らかな2次ベジェ曲線へ再構築します：
     - **同色マージ（`OverlayRule::Union`）**: 同じ色のシェイプと重なった場合、1つの滑らかな塗りシェイプに融合します。
     - **異色カット（`OverlayRule::Difference`）**: 異なる色のシェイプの上に描いた場合、下のシェイプから重なった領域を切り抜き（または分断）します。
4. **選択ツール（`V`）による「ハンドルなしの輪郭つまみ変形」**
   - **塗り選択・移動・削除**: シェイプ内部をクリックすると Flash 風のドット柄（Polka-Dot）ハイライトで選択状態になり、ドラッグで移動（ドロップ時にマージ判定）、`Delete` / `Backspace` キーで削除できます。
   - **輪郭の直接ドラッグ変形**: 輪郭（エッジ）にマウスを近づけるとカーソルに曲線アークバッジが表示され、そのままドラッグするとベジェハンドルを出さずに `B(t) = (1-t)^2 P0 + 2t(1-t) P1 + t^2 P2` から制御点 `P1` を逆算して輪郭がグニャッと曲がります。
   - **角（頂点）のドラッグ＆スナップ吸着**: 輪郭のアンカーポイントをドラッグすると頂点座標を直接移動でき、周囲の他の頂点に近づくとスナップ（吸着）します。

## ツールとショートカット

| キー | ツール | 機能 |
| :--- | :--- | :--- |
| **`B`** | **ブラシツール** | 太さ（Size）スライダー、100%スムージング固定、カラーピッカー＆プリセットパレット |
| **`E`** | **消しゴムツール** | 描いた軌跡の閉輪郭で既存すべてのシェイプに対して Boolean Difference を実行（削り取り・切断） |
| **`K`** | **バケツツール** | 線に囲まれた閉領域（穴）へのベクター色流し込み、既存シェイプの色変更、**選択領域のみへの色流し込み** |
| **`I`** | **スポイトツール** | キャンバス上のシェイプをクリック／ドラッグして塗りの色を抽出（カーソル横に抽出色のリアルタイムプレビュー表示） |
| **`V`** | **選択・輪郭変形ツール** | 塗りの選択・移動・削除、**矩形選択（部分スライス対応）**、**Shift + 連続矩形選択**、輪郭エッジのつまみ変形・横断分割、頂点移動＆スナップ吸着 |
| **`Q`** | **自由変形ツール** | 選択オブジェクトの**回転**（Shiftで15°スナップ）、**拡大・縮小**（Shiftで縦横比固定、Altでピボット中心）、**反転**（ハンドル越えドラッグ／左右・上下反転ボタン）、**基準点（ピボット○）の移動** |
| **`+` / `-`** | **アンカー追加・削除** | 選択ツール（`V`）使用中に `+` で曲線上にアンカー追加、`-` で既存アンカー削除（前後のアンカー間を直線化） |
| **`Esc`** | **選択解除** | 選択状態の解除（未編集の矩形スライスは元の形状へ無劣化復元） |
| **`Delete` / `Backspace`** | **削除** | 選択中の塗りシェイプ・矩形スライス領域を一括削除 |
| **`Cmd/Ctrl + Z` / `Y`** | **Undo / Redo** | 履歴の元に戻す・やり直し |
