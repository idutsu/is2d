# レビューと修正の繰り返し（review-loop）

Claude と Gemini のゼロベースレビュー → まとめと**あなたへの手紙** → **あなたの返事** → 直す → 審査 → プッシュ → またレビュー、を Mac の上で自動で繰り返します。あなたがすることは、手紙を読んで返事のファイルを置くことだけです。

## 始め方

1. claude・agy・cargo・git が使えるターミナルで、リポジトリに入る
2. `agy models` で、Gemini 4 Carbon の名前を確かめる
3. 登録する：`AGY_MODEL=<その名前> sh review-loop/install.sh`
   - すぐに1回目の見回りが動き、そのときのコミットのレビューが始まります（何時間もかかります）
   - 初めてのときは、先に `sh review-loop/loop.sh` を手で1回流して、`git fetch` とプッシュが通るか（GitHub の認証）を確かめると安心です

## ファイル（どれも `claude/review-loop/` の中）

| ファイル | 書く人 | 中身 |
|---|---|---|
| `<コミット>-手紙.md` | AI | 感想、この順に直すのがよいと思うもの、決めてほしいこと、返事の書き方 |
| `<コミット>-返事.md` | **あなた** | 何を直すか、決めてほしいことへの答え（書き方は手紙の最後にあります） |
| `<コミット>-報告.md` | AI | 直したもの・審査で落としたもの・直さなかったもの・Mac で確かめてほしいこと |
| `止まった.md` | AI | 途中で止まった理由。中を見て、このファイルを消すとやり直します |
| `保存していない変更があります.md` | AI | リポジトリのフォルダにコミットしていない変更があるので、見回りが待っていること（変更が無くなれば消えて続きます） |
| `STOP` | あなた | 置いておくと、見回りが何もしなくなります（消すと再開） |
| `progress.log` | AI | 進み具合 |

手紙・報告・止まったときは、Mac の通知でも知らせます。

## 1巡の流れ

レビューも直す作業も、このリポジトリのフォルダ（`/Users/dskzts/is2d`）で行います。見回りのたびに、フォルダを GitHub の最新に追いつかせます（`git pull --ff-only`）。なので、手元のフォルダはいつも最新です。

1. 見回り（10 分ごと）が、最新のコミットに手紙が無いのを見つける → レビュー（Claude → Gemini の順。計測がぶつからないよう同時には動かさない）→ まとめ（`claude/review-<コミット>-merged/summary.md`）→ 手紙
2. あなたが返事のファイルを置く
3. 見回りが返事を見つける → Claude が直す（1件1コミット、前のコードで失敗するテストつき）→ Gemini が1コミットずつ審査し、落としたものは戻す → 整形・全テスト・clippy をもう一度確かめる → `claude/planar-map-overlay` にプッシュ → 報告
4. プッシュでコミットが変わるので、次の見回りでまた1から

## 直しを戻したいとき

次の手紙への返事に「M-003 の直しを戻して」と書きます。

## 同じコミットで、返事をやり直したいとき

`<コミット>-返事.md` と `<コミット>-報告.md` を消して、新しい返事を置きます。

## 止める・外す

- 一時的に止める：`claude/review-loop/STOP` を置く
- 登録を外す：`sh review-loop/uninstall.sh`

## 中身

| ファイル | 役目 |
|---|---|
| `loop.sh` | 見回り1回分。ファイルの有る無しで、今どの段かを決める |
| `../review-all.sh` | レビュー2つとまとめ・手紙 |
| `../review-prompt.md` | ゼロベースレビューの手順書 |
| `../review-merge-prompt.md` | まとめと手紙の手順書 |
| `fix-prompt.md` | 直す手順書（Claude） |
| `check-prompt.md` | 審査の手順書（Gemini） |
| `finalize-prompt.md` | 落とした直しを戻して報告を書く手順書（Claude） |
| `install.sh`・`uninstall.sh` | launchd への登録と取り外し |

## 気をつけること

- 見回りが動いている間は、このフォルダでファイルを書き換えないでください。コミットしていない変更があると、見回りは何もせずに待ちます（あなたの作業を消さないため）。
- AI が途中で止まって、フォルダにコミットや変更を残したときは、それを `auto-review-<コミット>` か `auto-fix-<コミット>` というブランチに移してから、フォルダを元に戻します。消えはしないので、あとで中を見られます。
- 人のいない所で進めるため、どちらの AI も、コマンドとファイルの書き込みを自動で承認して動かします（`--dangerously-skip-permissions`）。
